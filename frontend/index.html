Alur Main

  1. Semua pemain membuka aplikasi dari server lokal yang sama.
  2. Host mengisi nama, upload audio dan file .lrc, lalu klik Buat Room.
  3. Pemain lain mengisi nama, memasukkan kode room, lalu klik Gabung Room.
  4. Host menekan Start Match untuk countdown sinkron.
  5. Skor dan posisi leaderboard diperbarui secara real-time selama permainan berjalan.
